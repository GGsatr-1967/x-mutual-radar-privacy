X互关雷达 隐私政策

生效日期：2026年11月11日 · 适用于 V3.2.1

本政策说明独立开发的 Chrome 扩展「X互关雷达」（下称“本扩展”）如何处理用户在 X（原 Twitter）平台上的关注关系信息。本扩展与 X 平台无官方关联。

1. 处理哪些数据

  • 在用户浏览 X 相关页面时，本扩展读取页面中可见的 X 用户名、显示名称、关注状态、头像地址及用于观察的时间信息，以辅助识别和复查关注关系。
  • 扫描记录、观察记录、头像地址和扩展界面位置等信息存储于浏览器的本地扩展存储空间。
  • 本扩展通过 Supabase 创建匿名登录会话；用于维持会话的访问令牌、刷新令牌及过期时间保存在浏览器本地扩展存储空间。匿名登录不要求用户提供邮箱或密码。
  • 用户主动选择提交云端报告时，扩展向云端发送被报告账号的 X 用户名及相关报告请求信息；服务端可能记录报告提交时间、匿名报告者标识和审核状态。

2. 使用目的

上述数据仅用于显示关注关系辅助检测结果、维护本地观察列表、支持用户主动提交报告、处理报告审核以及显示云端共享榜单。扫描结果可能受到 X 页面结构或关注关系变化影响，不保证完全准确。

3. 数据存储与第三方服务

本地观察数据主要存储在 Chrome 扩展的本地存储中。云端匿名身份认证、报告提交和共享榜单使用 Supabase 服务。扩展会与 X 页面及其头像资源发生正常浏览器交互。Supabase 可能依据其服务配置处理相关请求日志与技术信息。我们不会因安装扩展而自动将全部扫描记录上传为云端报告。

4. 云端榜单与审核

用户主动提交的报告需经过人工审核后，符合条件的账号用户名及报告人数才可能出现在共享榜单。榜单仅反映用户报告与审核结果，不是 X 官方认定，也不应被理解为对相关账号品行的评价。账号关注状态可能发生变化。

5. 数据保留与删除

用户可在扩展内移除相应的本地观察记录；卸载扩展通常会清除该扩展在浏览器中的本地存储数据。清除本地数据或卸载扩展不会自动删除已提交的云端报告。对于云端报告的更正、异议或删除请求，请通过下方联系邮箱提供相关 X 用户名和请求说明，我们将核实并处理。云端报告的保留期限取决于审核、纠错和运行所需；当前未设置统一的自动到期删除期限。

6. 信息共享与商业用途

本扩展不会将用户的本地扫描记录出售给广告商。经审核的共享榜单可能向使用本扩展的其他用户展示被报告账号的 X 用户名和汇总报告人数。我们不在榜单中公开匿名报告者的身份标识。

7. 安全

本扩展使用 HTTPS 与云端服务通信，并采用匿名会话与服务端权限控制。任何网络服务都无法保证绝对安全。请勿在报告中提供密码、私信或其他敏感信息。

8. 政策更新

如扩展的数据处理方式发生实质变化，我们会更新本政策及生效日期，并在适当位置告知用户。

9. 联系方式
